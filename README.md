
# VERO MVP Starter

Run from this folder:

```powershell
python app.py
```

Enter a startup name or website, such as:

```text
flatx.com
```

This first version:
- creates a structured startup case file
- generates a conservative investment report
- saves both as JSON
- never invents missing data

Next step: connect the profile pipeline to your existing startup database and then add evidence collection.
